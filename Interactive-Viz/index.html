What is this?

A short course that teaches you to read code — the kind an AI (Claude, Cursor, ChatGPT) writes for you — so you can tell good from broken, fix it, and steer the AI like a pro. You are not here to write code from a blank page.

Q

Am I learning to build a web app?

No. You're learning to read code in general. This page just happens to be a small web app — we use it as a live specimen to poke at.

Q

Which languages?

Both worlds you'll actually meet: JavaScript/web (what most AIs scaffold) and Python (scripts, servers, AI tools). Same ideas, slightly different spelling.

Q

Do I need to install anything?

No. Everything here runs in your browser. Click, predict, reveal. Guessing before peeking is the whole trick.

One thing before Lesson 2

The example project in Lesson 2 is a web app layout (a "Vite" project). We picked it on purpose: it's exactly what this page is built from (so you're reading something real), and it's the shape most AIs hand you. A Python project looks a little different — you'll see .venv/ instead of node_modules/, and requirements.txt instead of package.json — but the idea (your code vs installed parts vs the label) is identical.
