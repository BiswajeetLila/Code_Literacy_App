# Capstone Rubric

## Pass Requirements

- Playable 5-15 minute Unity vertical slice.
- Windows Steam-demo candidate package.
- Documented architecture.
- Scoped design spec.
- Human-vs-agent delegation map.
- Complete asset ledger with commercial-use and AI-disclosure fields.
- Passing smoke/build checks.
- Human playtest notes.
- Store copy and screenshot/trailer plan.
- Fresh-agent handoff that works.
- Defense of creative, technical, legal/commercial, and scope decisions.

## Fail Conditions

- No playable build.
- Unclear goal or controls after playtest.
- Missing commercial-use status for shipped assets.
- AI-generated player-consumed content not marked for disclosure.
- Agent-generated changes accepted without review.
- Fresh agent cannot continue from docs.
