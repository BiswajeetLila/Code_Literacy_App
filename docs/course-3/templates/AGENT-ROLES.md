# Agent Roles

## Director Agent

Keeps intent, scope, and decisions coherent.

## Producer Agent

Maintains task graph, blockers, and cut triggers.

## Gameplay Engineer Agent

Implements C# gameplay logic and test scenes.

## Tools Engineer Agent

Builds validators, editor tools, and debug overlays.

## Technical Artist Agent

Assists with import settings, materials, VFX notes, and style consistency checks.

## QA Agent

Writes repro steps, test plans, regression checks, and playtest scripts.

## Build Engineer Agent

Owns build profiles, release checklist, packaging notes, and Steam-demo candidate prep.

## Reviewer Agent

Reviews diffs, architecture fit, test evidence, and unscoped changes.
