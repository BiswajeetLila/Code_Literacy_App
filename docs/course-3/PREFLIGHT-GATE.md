# Course 3 Preflight Gate

## Purpose

Course 3 is open application, not casual open enrollment. This gate protects the studio pace.

## Placement Outcomes

- **Studio-ready:** learner starts Module 1.
- **Bridge-required:** learner completes a 1-2 week bridge and retests.
- **Not ready:** learner routes to Course 1/Course 2 foundations or Unity basics.

## Checks

The learner must demonstrate:

- Read a basic C# `MonoBehaviour` and identify `Start`, `Update`, fields, methods, and components.
- Explain GameObject, Component, Prefab, Scene, Inspector, Console, and Play Mode.
- Use git branches, inspect a diff, and recover from a bad change.
- Explain `Plan -> Execute -> Verify`.
- Use at least one coding agent in plan/review mode.
- Run Unity, enter Play Mode, inspect Console errors, and build a Windows player.
- Write a bug report with repro steps, expected behavior, actual behavior, and evidence.

## Bridge Pack

The bridge is a real pre-course, not a warmup handout.

- Unity orientation and editor basics.
- C# reading for agent-generated code.
- Git diff/revert/recovery.
- Agent plan/review workflow.
- Unity build troubleshooting.
- Prefab and scene basics.

Gate: retake the same preflight. No pass, no studio track.
