# Course 3 Cohort Operations

## Hardcore Default

- Length: 5 weeks.
- Pace: 2 modules/week.
- Workload: 18-30 focused hours/week.
- Live sessions: production briefing + critique/review each week.
- Capacity: 12-18 learners per studio lead.
- Staffing: add one technical reviewer/TA for every extra 6-8 learners.

## Slower Variant

- Length: 10 weeks.
- Pace: 1 module/week.
- Workload: 10-16 focused hours/week.

## Staff Roles

- **Studio lead:** pacing, scope cuts, creative bar, final pass/fail.
- **Technical reviewer:** Unity architecture, tests, build gates, agent safety.
- **Playtest support:** player clarity, bug reports, and final defense support.

## Review Rules

- Every module ends with artifact submission and gate evidence.
- Modules 3, 5, 8, and 10 require live or recorded defense.
- One resubmission window per failed gate.
- Two consecutive missed gates trigger mandatory scope cut.
- No playable build by Module 5 triggers recovery track.
