# Module 4: Unity Architecture For Agent Teams

## Objective

Create a project shape that agents can extend without creating tangled scene logic.

## Build

- Scene map.
- Prefab rules.
- ScriptableObject data rules.
- Input, events, UI, and save policy.
- Folder conventions and test structure.
- "Do not touch" boundaries.

## Gate

A reviewer agent can inspect a new feature and judge whether it fits the architecture.
