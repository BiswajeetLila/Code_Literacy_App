# Module 2: Game Concept To Vertical Slice Spec

## Objective

Turn a fuzzy idea into an implementable vertical-slice spec.

## Build

- Game thesis.
- Core loop.
- 3C: character, camera, controls.
- Player fantasy.
- Win/loss or success/failure condition.
- Scope, asset, and technical risk budgets.
- Human-vs-agent delegation map.
- Steam-demo candidate definition.

## Gate

Another agent could implement the first playable prototype without asking what the game is.
