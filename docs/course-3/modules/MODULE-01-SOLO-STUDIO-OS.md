# Module 1: Solo Studio Operating System

## Objective

Set up a Unity project that agents can safely inspect, modify, test, and review.

## Build

- Unity 6.3 LTS URP project.
- Git repo with Unity `.gitignore`.
- `AGENTS.md` / `CLAUDE.md` with Unity rules.
- Agent roles and approval policy.
- Throwaway MCP/editor automation safety test.

## Gate

A fresh agent can explain how to make a safe Unity change. Editor automation is either validated
for narrow use or explicitly cut.
