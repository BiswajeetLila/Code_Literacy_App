# Module 3: Prototype Tournament

## Objective

Use agents for breadth, then apply human taste and production judgment.

## Build

- 3-5 tiny playable prototypes.
- Scoring sheet for feel, novelty, feasibility, asset burden, extensibility, and risk.
- Kill memo for rejected prototypes.
- Chosen prototype with revision notes.

## Gate

The chosen prototype is playable in under 60 seconds and proves the core loop with placeholder art.
