# Module 6: Hybrid Asset And Technical Art Pipeline

## Objective

Build an art/audio pipeline that is style-consistent and commercially trackable.

## Build

- Style bible.
- Asset ledger with license, commercial-use, attribution, redistribution, and AI-disclosure fields.
- AI asset workflow.
- Asset Store/free-pack workflow.
- Import settings and naming rules.
- Technical-art review checklist.

## Gate

A new asset can be sourced or generated, imported, validated, documented, and used in-game without
breaking style, license, or disclosure clarity.
