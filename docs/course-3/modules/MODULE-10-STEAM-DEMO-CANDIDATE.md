# Module 10: Steam-Demo Candidate Package And Maintenance

## Objective

Package the vertical slice like a real demo candidate without requiring every learner to complete
Steamworks account-side setup.

## Build

- Windows build.
- Build profile.
- Release branch.
- Demo README.
- Known issues.
- Store copy draft.
- Screenshot set and trailer shot list.
- Steamworks checklist.
- Content Survey prep, including AI-content disclosure.
- Fresh-agent handoff.

## Gate

The output is a Steam-demo candidate package. Actual Steamworks upload is an optional extension.
