# Module 8: Verification For Games

## Objective

Build verification systems that fit game production.

## Build

- Edit mode tests.
- Play mode tests.
- Smoke test scene.
- Build verification checklist.
- Performance budget.
- Input checks.
- Playtest script.
- Bug report template.

## Gate

A broken core mechanic, failed build, missing reference, or packaging failure is caught before the
final release package.
