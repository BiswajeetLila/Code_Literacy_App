# Issue tracker: GitHub Issues

Issues and PRDs for this repo live in GitHub Issues:

https://github.com/BiswajeetLila/Code_Literacy_App/issues

Use the GitHub CLI at `C:\Program Files\GitHub CLI\gh.exe` when `gh` is not on `PATH`.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in this repository with the appropriate triage label from `docs/agents/triage-labels.md`.

PRDs are parent issues. Implementation issues should link back to the parent PRD issue and name any blocking issues.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue and its comments with the GitHub CLI. The user will normally pass the issue number or URL.
